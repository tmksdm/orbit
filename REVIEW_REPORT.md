## Fixes — MINOR-01/02 (исправлено)

### MINOR-01 — неопределённое состояние кольца без опорной даты

**Замечание:** в `DESIGN.md` не был явно описан случай `createdAt = NULL` при
отсутствии истории взаимодействий.

**Что сделано:** в §5 добавлен блок «Кольцо без опорной даты (срок не
рассчитывается)» с утверждённым владельцем визуальным поведением:

- число `recommendedIntervalDays` внутри кольца **показывается**;
- трек остаётся **нейтральным** (цвет `line`, без заполнения);
- цветная дуга прогресса **не отображается**;
- контакт **не получает** состояние «пора связаться»;
- дата следующего контакта **не показывается** как рассчитанная.

Поведение распространено на оба экрана и зафиксировано как единое:
§1 (семантика кольца), §5 (компонент), §6.1 (карточка списка), §6.3 (карточка
контакта), §12 (отображение данных из domain).

### MINOR-02 — некорректный текст при пустой истории

**Замечание:** в §6.3 подсказка об отсчёте от даты добавления показывалась всегда,
хотя это верно только при известном `createdAt`.

**Что сделано:** текст пустой истории разделён по опорной дате:

- при **известном** `createdAt`: «Взаимодействий пока нет. Отсчёт идёт от даты
  добавления контакта.»;
- при `createdAt = NULL` и пустой истории: **«Взаимодействий пока нет. Срок
  следующего контакта пока не рассчитан»**.

Дополнительно в §6.3 плитка «следующий контакт» не показывает рассчитанную дату,
если срок не рассчитывается (точная подача — §13, пункт 8). В §13 добавлен пункт 8
(вид подачи «срок не рассчитан»).
