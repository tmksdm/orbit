# Прототип: PWA без backend (изолированный)

PWA-прототип для архитектурного исследования Orbit. **Не часть приложения Orbit.**

Содержимое: экран, локальное хранение (`localStorage`), попытка запланировать
локальное уведомление через `showTrigger`/`TimestampTrigger`.

## Фактический результат

- Notification Triggers (`showTrigger`/`TimestampTrigger`) **не поставляется** в
  основной платформе (статус Chrome: `Launch: Not started`, требуется флаг) —
  см. `docs/architecture-research.md` §5.1.
- Поэтому запланировать локальное уведомление **без backend** (и без постоянно
  открытой страницы) через PWA на основной платформе **нельзя**. Прототип
  показывает только немедленное уведомление, пока страница активна.
- Дополнительные ограничения автономности: вытеснение хранилища браузером и
  автоматический отзыв разрешений уведомлений у неактивных сайтов (Chrome, 2025).

**Вывод:** PWA не закрывает ключевое требование Stage 4 (локальные напоминания без
backend). Вариант отклонён как основной стек.
