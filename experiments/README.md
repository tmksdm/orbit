# experiments/ — изолированные архитектурные прототипы

**Важно:** содержимое этого каталога — **экспериментальные прототипы архитектурного
исследования** (поручение владельца, 2026-10-10). Они **не** являются частью
работающего приложения Orbit, **не** подключены к его сборке, тестам, CI, lint и
typecheck (`eslint.config.js` игнорирует `experiments/`, корневые скрипты их не
видят). Основной Orbit не менялся.

Назначение — получить **измеримые** факты для сравнения стеков: размер
установочного пакета, размер основных компонентов, возможности фоновых напоминаний
без backend.

| Каталог | Что это | Статус измерения |
|---|---|---|
| `kotlin-views/` | Минимальное нативное Android-приложение (Kotlin + Android Views): экран, локальное хранение (SharedPreferences), планирование локального напоминания (`AlarmManager.setAndAllowWhileIdle` + `BroadcastReceiver` + `BOOT_COMPLETED`). | Собирается Gradle; размеры APK см. отчёт |
| `pwa/` | PWA без backend: экран, локальное хранение (`localStorage`), попытка запланировать локальное уведомление (`showTrigger`/`TimestampTrigger`). | Показывает фактическую невозможность локального уведомления по расписанию без backend на основной платформе |

Отчёт и рекомендация — `docs/architecture/ADR-stack-choice.md` (в проекте Orbit).
Владелец должен рассмотреть его и принять решение; автоматической миграции нет.
